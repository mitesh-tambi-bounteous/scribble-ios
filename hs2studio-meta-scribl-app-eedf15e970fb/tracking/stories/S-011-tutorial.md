# S-011 -- Tutorial / onboarding

The tutorial introduces the daily loop to a new user after sign-up. In the POC
it is one or more skeleton onboarding panels that explain the loop and then hand
off to the splash/start screen.

## AC

- [ ] A named "Continue"/"Get started" button navigates to the Splash/Start
  screen (S-009).
- [ ] The screen shows skeleton onboarding panel(s) only.
- [ ] The screen ships first as a skeleton with working navigation, then design
  fidelity follows in a later pass.
- [ ] The screen renders and behaves identically on the web export and on an
  iOS/Android device or simulator from the single Expo/React Native codebase.
