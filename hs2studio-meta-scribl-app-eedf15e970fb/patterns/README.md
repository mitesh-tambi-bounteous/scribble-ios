# patterns/

Reusable learnings: design patterns, workflows, and architectural references
that hold beyond this single engagement. When something learned here would help
the next project, it belongs in a pattern.

Adapted from the brain vault's patterns folder.

## Conventions

- One pattern per file, named for the idea (for example `surgical-changes.md`).
- A pattern states: the recurring situation, the approach that works, and when
  not to use it.
- Engagement-specific observations stay in `reviews/`. Patterns are the
  cross-project distillate; the strongest ones are published back to the
  methodology engine so every future brain inherits them.
