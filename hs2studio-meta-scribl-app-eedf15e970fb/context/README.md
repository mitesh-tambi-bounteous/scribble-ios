# context/

Persistent project context: the standing facts an agent should know to work on
this engagement well. Stakeholders, the client, constraints, brand and tone,
domain background, and anything that should not have to be re-derived each
session.

Adapted from the brain vault's context folder.

## Conventions

- Keep it current and short. This is reference, not a log.
- Suggested files: `client.md`, `stakeholders.md`, `constraints.md`,
  `glossary.md`. Add only what is genuinely durable.
- Read context at the start of non-trivial work; update it when the standing
  facts change.
