# Post-Workshop App Flow (Live Build)

Captured **after the Scribl.co discovery workshop** (Mon Jul 20 2026), this is the
current, *running* build -- real screens from the live app (not a mockup), signed in
as a real family account and wired in journey order.

During the workshop we took the client's in-room feedback and implemented it live,
folding the changes straight into the build so the version at the end of the session
already reflected their asks. The enhancements visible below:

- **Custom brushes** and an expanded brush set
- **More brush sizes**
- **2x the color palette** (16 colors)
- **Comments removed** -- replaced by lightweight reactions
- **Multi-day wall history** -- scroll back through previous days on a wall
- **Custom avatars** -- create a custom avatar right from the Home screen
- Plus **AI-generated backgrounds** behind each drawing

![Scribl live app flow -- post-workshop build](/assets/context/scribl-live-app-flow-2026-07-20.png)

The flow reads left to right: **Sign up -> Tutorial -> Home -> Draw -> Caption + voice
-> Family wall -> Drawing**. The Home, Draw, Family wall, and Drawing screens
(highlighted) carry the enhancements above.

Compare against the [Original Wireframes](./original-wireframes) supplied by Scribl to
see how far the working build has moved from the initial hand-off.
