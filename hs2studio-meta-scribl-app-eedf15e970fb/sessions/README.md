# sessions/

AI work-session transcripts. A durable log of what was done with the agents
during the engagement: prompts, decisions, and outcomes worth keeping.

Adapted from the brain vault's daily-sessions folder.

## Conventions

- One file per session, named by ISO date (for example `2026-06-30.md`). Append
  multiple sessions in a day under dated headings if needed.
- Capture what was attempted, what worked, and what to resume next.
- Session logs feed end-of-stage reviews in `reviews/`; pull recurring friction
  out into `patterns/` or, if it is methodology friction, into an edit to the
  methodology engine plus a back-flow PR.
