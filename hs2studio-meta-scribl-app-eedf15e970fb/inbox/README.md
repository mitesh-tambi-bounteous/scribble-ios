# inbox/

Raw capture. The single place to drop unprocessed inputs: ideas, links, pasted
notes, dumps. Route from here into the right home; do not let things accumulate.

Adapted from the brain vault's inbox folder.

## Conventions

- Anything captured here is temporary. Process it promptly into its destination:
  - source material and transcripts -> `knowledge/`
  - reusable learnings -> `patterns/`
  - project context -> `context/`
  - work items -> `tracking/stories/`
- The inbox should trend toward empty. Routed items are deleted from here.
